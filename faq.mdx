Below are answers to the questions we hear most from pipefitters using PipeFitter. If your question isn't covered here, check the [Troubleshooting](troubleshooting) page or reach out to [support@pipefitter.app](mailto:support@pipefitter.app).

<AccordionGroup>
  <Accordion title="Does PipeFitter work without an internet connection?">
    Yes. After the first load, all calculators and reference data are cached in your browser and work without an active internet connection. No Wi-Fi, no problem — ideal for underground work, mechanical rooms, and remote job sites.
  </Accordion>

  <Accordion title="Does PipeFitter work on my phone?">
    Yes. PipeFitter is designed to work on any modern smartphone or tablet. The interface is optimised for small screens with large tap targets, making it usable even with gloves on. It works on iOS (Safari) and Android (Chrome) as well as desktop browsers.
  </Accordion>

  <Accordion title="Does it support metric units?">
    Yes. Every calculator and reference table supports both imperial (feet-inch-fractions) and metric (millimetres). Use the unit toggle at the top of any calculator to switch. All values convert automatically.
  </Accordion>

  <Accordion title="How accurate are the calculations?">
    PipeFitter uses full trigonometric precision internally. Displayed results are rounded to the nearest 1/16" in imperial mode and to 0.1 mm in metric. All ASME reference data is sourced from verified standard editions.
  </Accordion>

  <Accordion title="What fitting take-out values does the app use?">
    Take-out values are calculated from the ASME B16.9 centre-to-face dimensions for standard long-radius elbows. The app looks up the correct take-out automatically based on the pipe size you select.
  </Accordion>

  <Accordion title="Which ASME standards are included?">
    PipeFitter reference tables cover:

    - **ASME B36.10M** — pipe dimensions and weights
    - **ASME B16.9** — butt weld fitting dimensions
    - **ASME B16.28** — short-radius elbows
    - **ASME B16.5** — flange dimensions
    - **ASME B1.20.1** — NPT thread engagement
  </Accordion>

  <Accordion title="Do I need to create an account?">
    No account is required. Open the app and start calculating — no sign-up, no login, no personal information needed.
  </Accordion>

  <Accordion title="Is there a cost to use PipeFitter?">
    PipeFitter is free to use. All 7 calculators and 5 reference tables are available at no charge — just open the app in your browser and get to work.
  </Accordion>

  <Accordion title="Can I save or export my calculations?">
    Calculation results are displayed on screen for you to note or photograph. PipeFitter does not currently offer PDF export or cloud saving — your inputs are not stored between sessions.
  </Accordion>

  <Accordion title="What browsers are supported?">
    PipeFitter supports the current versions of Chrome, Safari, Firefox, and Edge. JavaScript must be enabled.
  </Accordion>
</AccordionGroup>
