PipeFitter is designed for fast, glove-friendly use in the field. Large tap targets, high-contrast labels, and a custom numpad with fraction buttons mean you can get a result without squinting or fighting autocorrect. This page covers the app's layout, how to switch between tools, unit settings, and tips for getting results quickly.

## App Layout

Every screen in PipeFitter shares the same three-part structure:

- **Top navigation bar** — contains the PipeFitter logo, the unit switcher (imperial / metric), and a menu icon that opens the full tool list. The navigation bar is always visible so you can switch tools or units without scrolling.
- **Calculator / Reference tabs** — just below the navigation bar, these tabs let you jump between the Calculators section and the Reference Tables section with a single tap.
- **Input and results area** — the main body of the screen. Inputs appear in the upper portion; results and the live diagram appear below. On wider screens (tablet and desktop), inputs and results sit side by side.

## Switching Tools

Tap or click any calculator or reference table from the main menu. The menu is grouped by category — Offset Calculators, Cut Calculators, Area & Volume, and Reference Tables — so the tool you need is always within one or two taps. PipeFitter remembers your last-used tool between sessions, so if you close the browser and reopen it, you land right back where you left off.

## Entering Values

### Imperial fractions

Enter feet, inches, and fractions in their own separate fields. For example, a measurement of 3 ft 6-1/2 in goes into three fields: **3** (feet), **6** (inches), **1/2** (fraction). The custom numpad provides dedicated fraction buttons — 1/8, 1/4, 3/8, 1/2, 5/8, 3/4, and 7/8 — so you can enter a tape measure reading directly without converting to decimals in your head.

### Metric

In metric mode, all values are entered as a single number in millimetres. The fraction buttons are hidden and replaced with a standard numeric keypad.

### Preset angles

Common fitting angles are available as one-tap presets directly below the angle label: **11.25°**, **22.5°**, **30°**, **45°**, and **60°**. Tap the preset that matches your fitting and the angle field fills automatically. Tap **Custom** to type in any angle — useful for fabricated or non-standard fittings.

## Reading Results

Output fields highlight automatically once PipeFitter has enough input to calculate a result — there's no submit button to press. The live diagram below the results updates in real time to reflect your current inputs, giving you an instant visual sanity check. If a result doesn't look right, compare it against the diagram to spot where the geometry may be off. Tap any result field to copy its value to your device clipboard.

## Switching Units

The unit toggle (imperial / metric) appears at the top of every calculator and reference table. Switching units does two things at once: it converts all values currently shown on screen to the new unit system, and it switches the input fields to match. You never lose your work — if you entered a rise of 1 ft 6 in and switch to metric, PipeFitter converts it to 457 mm automatically.

<Tip>
  If you measure a cut with a tape and the fraction is hard to read, open the **Fraction Reference** table. It lists the decimal inch equivalent for every common fraction from 1/64 to 63/64, so you can confirm the value before entering it into a calculator.
</Tip>

## Browser Compatibility

PipeFitter works in modern versions of all major browsers:

| Browser | Minimum supported version |
|---|---|
| Google Chrome | 90 or later |
| Apple Safari | 14 or later |
| Mozilla Firefox | 88 or later |
| Microsoft Edge | 90 or later |

Make sure JavaScript is enabled in your browser settings — PipeFitter requires it to run the calculators and render the live diagrams. If you see a blank screen or missing results, check that JavaScript is not blocked by a browser extension or enterprise policy.
