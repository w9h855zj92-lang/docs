Most issues with PipeFitter are quick to resolve. Work through the relevant section below and you should be back up and running in minutes. If you're still stuck, contact support at [support@pipefitter.app](mailto:support@pipefitter.app).

## The app won't load or shows a blank screen

<AccordionGroup>
  <Accordion title="Steps to fix a blank screen or failed load">
    - Make sure JavaScript is enabled in your browser.
    - Try a hard refresh: **Ctrl+Shift+R** (Windows/Linux) or **Cmd+Shift+R** (Mac).
    - Clear your browser cache and reload.
    - Try a different browser — Chrome or Safari are recommended.
  </Accordion>
</AccordionGroup>

## Calculations seem wrong

<AccordionGroup>
  <Accordion title="Steps to diagnose incorrect calculation results">
    - Check that your units are set correctly (imperial vs metric). A rise entered in inches with the unit set to mm will produce incorrect results.
    - Confirm the fitting angle matches your actual fittings. Using a 45° multiplier with 30° fittings gives incorrect results.
    - Verify your rise measurement — the most common source of error is measuring the wrong dimension in the field.

    <Note>
      The calculators assume standard long-radius (LR) elbows for take-out. If you're using short-radius (SR) elbows, take-out values will differ.
    </Note>
  </Accordion>
</AccordionGroup>

## The app doesn't work offline

<AccordionGroup>
  <Accordion title="Steps to restore offline functionality">
    - On the first visit, PipeFitter loads all its assets from the server and caches them in your browser.
    - If you've never loaded the app on that device before, you need a connection for the first load.
    - If offline mode stopped working, clear your browser cache and reload with a connection to re-cache the app.
  </Accordion>
</AccordionGroup>

## Fractions are not appearing correctly in inputs

<AccordionGroup>
  <Accordion title="Steps to fix fraction input issues">
    - Make sure you're using the in-app fraction keypad rather than typing raw decimals into fraction fields.
    - If pasting values, use decimal format (e.g., `12.5` for 12-1/2") and ensure you're in the correct unit mode.
  </Accordion>
</AccordionGroup>

## The app looks broken on my phone

<AccordionGroup>
  <Accordion title="Steps to fix display issues on mobile">
    - Ensure your browser is up to date. PipeFitter requires a modern browser released within the last two years.
    - Try rotating to landscape mode for wider calculator inputs.
    - Disable any browser extensions that may be interfering with the page layout.
  </Accordion>
</AccordionGroup>

## Reference table shows no data

<AccordionGroup>
  <Accordion title="Steps to fix an empty reference table">
    - Tap or click the search field and enter a valid NPS (e.g., `2` or `2 inch`).
    - If data still doesn't appear, try refreshing the page. On first load, reference data may take a moment to initialise.
  </Accordion>
</AccordionGroup>

---

<Note>
  If none of the steps above resolve your issue, contact the support team at **support@pipefitter.app** with a description of the problem and the device and browser you're using.
</Note>

<Tip>
  Bookmark the app URL after your first successful load. This ensures the app is fully cached in your browser and available the next time you're working without a connection.
</Tip>
