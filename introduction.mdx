PipeFitter is a web app that gives pipefitters, welders, HVAC techs, and plumbers instant access to the calculations and reference data they need on the job. Open it in any modern browser and you have a full suite of pipe layout and fabrication tools ready to use — no installation required, and no internet connection needed after the first load.

## Who Uses PipeFitter

PipeFitter is built for anyone who runs, fabricates, or inspects pipe in the field or the shop. That includes:

- **Journeyman pipefitters** laying out offsets, spools, and complex rolls on the job site
- **Apprentices** learning offset math and verifying their hand calculations
- **Foremen and estimators** checking cut lengths and material quantities quickly
- **Plumbers** working with NPT threaded pipe and needing thread engagement data
- **HVAC technicians** sizing duct and pipe runs in commercial and industrial systems

## ASME-Verified Data

Every value in the reference tables is sourced directly from ASME standards. You can trust the numbers in PipeFitter the same way you trust your code book.

| Table | Source Standard |
|---|---|
| Pipe Dimensions | ASME B36.10M |
| Pipe Weights | ASME B36.10M |
| Butt-Weld Fittings | ASME B16.9 |
| Short-Radius Fittings | ASME B16.28 |
| Flanges | ASME B16.5 |
| Thread Engagement | ASME B1.20.1 |

## Units

PipeFitter supports both imperial and metric measurement. In imperial mode, you enter feet, inches, and fractions separately — the custom numpad provides fraction buttons (1/8 through 7/8) so you can dial in a field measurement without hunting for a decimal equivalent. In metric mode, all values are entered and displayed in millimetres. You can switch units at any time using the toggle at the top of any calculator; PipeFitter converts your current inputs and outputs automatically.
