The Fraction Reference chart converts common imperial fractions to their decimal equivalents — useful when entering measurements into a calculator that accepts decimals, or when reading a digital readout and needing to convert back to a fraction for marking pipe. Keep this handy any time you're moving between a tape measure and a digital tool.

## Conversion chart

The table below covers every 1/16" increment from 1/16" through 15/16". These are the fractions you'll encounter most often on a tape measure, a pipe layout, or a cut sheet.

| 1/16"    | 0.0625           |
| 1/8"     | 0.125            |
| 3/16"    | 0.1875           |

| 5/16"    | 0.3125           |

## Converting to millimetres

To convert any decimal inch value to millimetres, multiply by **25.4**:

```
Decimal inches × 25.4 = Millimetres
```

The table below lists the most commonly needed conversions for quick reference:

| Fraction | Inches | Millimetres |
|----------|--------|-------------|
| 1/8"     | 0.125  | 3.18 mm     |
| 1/4"     | 0.250  | 6.35 mm     |
| 1/2"     | 0.500  | 12.70 mm    |
| 3/4"     | 0.750  | 19.05 mm    |

For any value not in the table, use the formula above. For example, 3/8" = 0.375 × 25.4 = **9.525 mm**.

<Tip>
  PipeFitter's calculators accept **feet-inch-fraction inputs natively** — you can type dimensions exactly as you'd read them off a tape measure, without any decimal conversion. You only need this chart if you're doing manual calculations alongside the app, or if you're entering measurements into a third-party tool that requires decimal inches.
</Tip>
